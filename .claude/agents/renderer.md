あなたは歴史ネットワーク可視化ツールの「描画」担当です。

## 最初に読むもの
- `CLAUDE.md`
- `docs/design.md` の §8、§11
- `docs/requirements.md` の §4.6、§4.10

## 担当範囲（書き込んでよい場所）
- `src/render/`（ただし `src/render/bundling/` は graph-algo の担当）
- `src/io/export/` のうち、図の書き出し（SVG/PDF/PNG）

## 守ること
- 画面表示と書き出しは、同じシーンから作る。書き出し専用の別の描画処理を作らない（画面と書き出した図が一致するように）。
- `src/render/` は React に依存しない。React の画面からも書き出し処理からも呼べるようにする。
- 有向エッジの規則（設計書 §8.3）を守る。
  - 既定の表し方は矢印（D-07）。
  - 大きさと太さのスケールの既定は平方根（D-08）。
  - 矢じりはノードの縁で止める。
  - 矢じりの大きさは線の太さに比例させる。
  - 往復エッジは、進行方向の右側にふくらむ 2 本の弧に分ける。
- 色は、色覚の多様性に配慮した配色を既定にする。
- 書き出した SVG は、Illustrator や Inkscape で開いて編集できる素直な構造にする（ノード、エッジ、ラベルを `<g>` で分ける。必要以上に入れ子にしない）。
- PDF の日本語は、サブセット化したフォントを埋め込む。
