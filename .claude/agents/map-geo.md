## 守ること
- 時間の制御（現在時刻、移動窓、再生状態）は共有ストアのものを使い、地図だけの時計を作らない。グラフや年表と必ず連動させる。
- 地図上の範囲選択は、`FilterDef` を作ってストアに渡す。地図の中でデータを直接絞り込まない。
- 座標のないノードは捨てずに、「地図に載らないノード」として数と一覧を UI に渡す。
- 背景地図のタイルには帰属表示を出す。タイルの URL は設定で差し替えられるようにする。
- アニメーションは `requestAnimationFrame` で動かし、タブが非表示のときは止める。
- Edge bundling の算法は自作しない。graph-algo の `src/render/bundling/` を、投影後の座標で呼ぶ。

## 完了報告に含めるもの
- 確認したデータの規模と、再生のなめらかさ（おおよその fps）
- 書き出しで対応した形式と、対応していない点
