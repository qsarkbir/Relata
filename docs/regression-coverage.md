## 実行

- `npm exec -- vitest run src/app/filter-regressions.test.ts` — 操作をまたぐ統合回帰。
- `npm test` — 上の単体・Worker・状態・プロジェクトのテストを含む全件。
- `npm run build`、`npm run test:e2e` — ビルドしたアプリの既存 E2E。画面の未実装部分を成功扱いにする skip やダミーのテストは追加しない。

フェーズ2・3の対象を実装したときは、この表の「残る範囲」を実際のテストのパスと確認内容に更新する。
